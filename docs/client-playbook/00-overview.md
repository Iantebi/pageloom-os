# 00 — Overview

## Goal

Give the Owner one linear map of the whole customer journey — from a closed deal to a
live, supported website — independent of the CRM and of Backend Master.

## How this playbook maps to the real system

| Stage | System surface |
|---|---|
| 01 Lead Closed | Wherever the deal was actually closed (a call, a proposal, or the CRM's own leads pipeline) — outside this playbook's tooling. |
| 02 Create Client | Owner Workspace → **New Client** (`/clients/new`). One form, four required fields. |
| 03 Send Discovery | The generated Discovery link (`/d/{token}`) and WhatsApp message, copied from the New Client success screen. |
| 04 Discovery Completed | The customer's own Business Discovery session (9 sections), submitted from their link. |
| 05 Build Preparation | Owner Workspace → Discovery (`/discoveries`), reviewing the submitted answers and uploaded files. |
| 06 Website Build – 08 Internal QA | The project's internal workflow stages (research → brand strategy → design system → sitemap → UX → UI → copywriting → SEO → development → QA). |
| 09 Customer Review – 12 Final Approval | The customer's Website Review card in their portal (Final Approval / Request Revisions), with up to two included revision rounds. |
| 13 Domain & Publish | The launch checklist and final deployment approval. |
| 14 Website Live | Handover — live URL, support and maintenance information. |
| 15 Support | Ongoing support tickets and maintenance renewal. |

## Owner Tasks

- Know which stage a given customer is in before contacting them (check `/discoveries` or the customer's project in `/crm`).
- Never skip 02 (Create Client) — it is the only supported way to get a customer a Discovery link. Manually creating Firestore documents or building a Discovery URL by hand is never necessary and is not supported.

## Customer Tasks

- None at this stage — this document is Owner-facing only.

## Checklist

- [ ] I know where each stage of this playbook happens in the product.
- [ ] I understand that Discovery links are always generated by the New Client tool, never built or copied by hand.

There is no "exit" for an overview — move to [01 Lead Closed](./01-lead-closed.md) once a real deal exists.
