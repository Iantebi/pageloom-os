# 06 — Website Build

## Goal

Produce the actual website — research, brand strategy, design system, sitemap, UX
planning, UI, and copywriting — from the Discovery brief.

## Owner Tasks

- Track progress through the project's internal workflow stages (research → brand strategy → design system → sitemap → UX planning → UI generation → copywriting).
- Keep the customer's expectations set: no action is needed from them during this stage — say so if they ask.
- Escalate internally if a stage stalls; the customer should never be the one to notice a delay first.

## Customer Tasks

- None. This is explicitly a "no action needed" stage in the customer's own journey timeline.

## Checklist

- [ ] Brand direction matches what the customer actually described in Discovery (their words, not a generic template).
- [ ] Sitemap covers every service/page the customer asked for.
- [ ] Copywriting reflects the customer's own value proposition and differentiation answers.

## Exit Criteria

A complete, unpublished build exists and is ready for optimization. Move to
[07 SEO](./07-seo.md).
