# 11 — Revision Round 2 (if needed)

## Goal

Resolve the customer's second and, per the included plan, final revision round.

## Owner Tasks

- Same as Round 1: read the request, make the changes, resolve the record, move the project back to Customer Review.
- Know what happens next: if the customer asks for a **third** round, the product automatically declines with a polite, clear message — "your included revision rounds are complete; additional revisions need approval from the PageLoom team" — rather than silently accepting unlimited changes. If a third round is genuinely warranted (a scope change, a goodwill exception), that's a deliberate business decision the Owner makes directly with the customer, outside the self-service flow — the Owner can still create additional revision records on the customer's behalf; the self-service cap only applies to the customer's own requests.

## Customer Tasks

- Same as Round 1: list every remaining requested change together in this round.
- If they try to request a third round, they'll see the rounds-exhausted message instead of a form — this is expected, not an error.

## Checklist

- [ ] Every item in round 2's request has been addressed.
- [ ] The revision request record is marked resolved.
- [ ] The project is back in Customer Review.

## Exit Criteria

Round 2's changes are live. The customer should now be approving — proceed to
[12 Final Approval](./12-final-approval.md). Only escalate beyond this if the Owner has
explicitly agreed to an exception outside the standard two-round plan.
