# 13 — Domain & Publish

## Goal

Connect the customer's domain and take the approved site live — the one irreversible
step in the whole journey, so it gets a real readiness checklist, not a single click.

## Owner Tasks

- Work through the launch readiness checklist before publishing (hosting, SSL, domain DNS, backups, redirects from any previous site).
- Confirm the domain is either already owned by the customer (get DNS access or the records to add) or needs to be purchased/registered.
- Get sign-off from whoever holds final deployment authority internally before pushing live.
- Only publish once every required checklist item is complete — the checklist is a readiness aid, not a formality to skip.

## Customer Tasks

- Provide domain access or ownership details if PageLoom doesn't already manage the domain.
- Be reachable in case DNS propagation needs a quick confirmation call.

## Checklist

- [ ] Every required item on the launch checklist is complete.
- [ ] Domain DNS is configured (or the domain is newly registered and pointed correctly).
- [ ] SSL is provisioned and verified.
- [ ] Final deployment approval has been recorded internally.

## Exit Criteria

The site is live at the customer's real domain. Move to
[14 Website Live](./14-website-live.md).
