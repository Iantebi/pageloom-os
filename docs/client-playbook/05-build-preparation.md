# 05 — Build Preparation

## Goal

Turn the customer's Discovery answers into a build-ready brief before any design or
development work starts.

## Owner Tasks

- Review the submission in Owner Workspace → Discovery (`/discoveries`) or by opening the project directly.
- Read every answer — the customer's own words are the best source for tone, positioning, and priorities.
- Check the uploaded materials: are there enough real photos, or does the plan need to rely on AI-generated/stock imagery for some sections?
- Note anything ambiguous or missing that needs a quick follow-up message before the build starts (don't reopen the whole Discovery for one clarification — a WhatsApp question is faster).
- Assign the project internally (design, copy, dev) as your normal process requires.

## Customer Tasks

- None, unless the Owner has a clarifying question.

## Checklist

- [ ] Every Discovery section has been read, not skimmed.
- [ ] Uploaded materials are reviewed and categorized.
- [ ] Any open questions have been sent to the customer.
- [ ] The project is assigned internally and ready to enter the build stages.

## Exit Criteria

The team has everything it needs to start building. Move to
[06 Website Build](./06-website-build.md).
