# Client Playbook

The Owner's stage-by-stage guide to taking one paying customer from a closed deal to a
live, supported website. This is the Customer Journey's own documentation — it is
deliberately **standalone**: it does not live inside, reference, or depend on Backend
Master (platform administration) or the CRM (`/crm` leads pipeline). A deal can be closed
however the agency likes (a call, a proposal, a CRM lead); this playbook starts the moment
that deal is closed and the Owner is ready to onboard the customer directly.

Each stage below documents: **Goal**, **Owner Tasks**, **Customer Tasks**, **Checklist**,
and **Exit Criteria** — what "done" looks like before moving to the next stage.
